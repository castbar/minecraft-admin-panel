# Security Policy

## 🔒 Política de Seguridad

La seguridad es una prioridad para nosotros. Si encuentras una vulnerabilidad, por favor repórtala de forma responsable.

## 🚨 Reportar una Vulnerabilidad

**NO crear un Issue público** para vulnerabilidades de seguridad.

### Cómo Reportar

1. **Email directo**: security@castbar.dev
2. **Incluir:**
   - Descripción detallada de la vulnerabilidad
   - Pasos para reproducir
   - Impacto potencial
   - Sugerencias de mitigación (si las tienes)

### Qué Esperar

- ✅ Respuesta dentro de 48 horas
- ✅ Confirmación de recepción
- ✅ Actualizaciones sobre el progreso
- ✅ Notificación cuando se publique el fix

### Proceso

1. **Reporte**: Envías el reporte por email
2. **Confirmación**: Confirmamos recepción
3. **Investigación**: Investigamos la vulnerabilidad
4. **Fix**: Desarrollamos y probamos el fix
5. **Release**: Publicamos el fix en una nueva versión
6. **Disclosure**: Publicamos un advisory (si aplica)

## 🛡️ Versiones Soportadas

| Versión | Estado de Soporte          |
| ------- | -------------------------- |
| latest  | ✅ Soportada               |
| v1.x.x  | ✅ Soportada               |
| < v1.0  | ❌ No soportada            |

## 🔍 Áreas de Interés

Estamos especialmente interesados en vulnerabilidades relacionadas con:

- Autenticación y autorización
- Exposición de información sensible
- Inyección de código (SQL, XSS, etc.)
- Control de acceso
- Gestión de sesiones
- Exposición de APIs

## ✅ Buenas Prácticas

Para mantener el proyecto seguro:

- ✅ Nunca commitees credenciales o secrets
- ✅ Usa variables de entorno para configuración sensible
- ✅ Mantén las dependencias actualizadas
- ✅ Revisa PRs cuidadosamente
- ✅ Reporta vulnerabilidades de forma responsable

## 📜 Historial de Seguridad

Las vulnerabilidades corregidas se documentarán aquí después de ser resueltas.
